# SNI Proxy Deploy

Автоматизированный комплекс для развертывания SNI-прокси сервера, обхода блокировок для ИИ-сервисов и защиты от ТСПУ/DPI с поддержкой Xray и 3X-UI. 

Комплекс объединяет списки доменов из внешних источников (`dns.malw.link` и `GeoHideDNS`) и пользовательских доменов (`lists/custom_domains.txt`), обеспечивает прозрачное L4 SNI-проксирование на 443 порту, мультиплексирует входящий трафик с Xray Reality, прикидывается реальным сайтом (маскировка) и безопасно проксирует веб-панель 3X-UI без открытия нестандартных портов наружу.

---

## 🛡️ Что внутри:

* **Единый порт 443 (L4 Stream + L7 HTTP):**
  * **SNI-прокси для роутеров:** Запросы к разрешенным доменам (Google AI/Gemini, GitHub, WhatsApp и др.) прозрачно проксируются на L4-уровне к оригинальным серверам без расшифровки TLS.
  * **Xray VLESS-Reality:** Трафик с целевым SNI (например, `www.nvidia.com`) направляется в локальный Xray (`127.0.0.1:8443`). При сканировании Xray возвращает подлинный ответ маскировочного сайта (Akamai/Nvidia).
  * **Сайт-маскировка (Anti-TSPU Camouflage):** Любые другие запросы (по домену сервера, прямой заход по IP без SNI или активные зонды ТСПУ) перенаправляются на внутренний HTTPS-сервер (`127.0.0.1:8083`), отдающий полноценный легитимный веб-сайт с валидным сертификатом Let's Encrypt (HTTP 200, зеленый замок). Никаких разрывов соединений или сигнатурных ошибок `alert internal error`.
* **Скрытая веб-панель 3X-UI:** Веб-интерфейс панели изолирован на `127.0.0.1:53273` (внешний порт полностью закрыт от сетевых сканеров Censys/Shodan). Доступ к панели осуществляется через стандартный порт 443 по секретному пути: `https://ваш-домен.com/секретный-путь/`.
* **Скрытый сервис подписок (Subscription URL):** Сервис подписок 3X-UI изолирован на `127.0.0.1:2096` и проксируется через стандартный HTTPS порт 443 по случайному криптостойкому пути: `https://ваш-домен.com/s_случайный_токен/<subId>`. Любые обращения к типовым путям зондов (`/sub/`, `/subscribe`) возвращают легитимный белый сайт ApexEdge (HTTP 200). Клиентам выдаются ссылки с портом 443.
* **Автоматика сертификатов:** При запуске контейнер автоматически находит свежий SSL-сертификат в `/root/cert` или генерирует резервный для первичного старта.
* **Порт 80:** Автоматический 301-редирект на HTTPS и поддержка ACME-челленджей (`/.well-known/acme-challenge/`) для бесшовного автопродления сертификатов через `acme.sh` / `certbot`.
* **Dual-Stack на роутерах OpenWrt:** Маршрутизатор генерирует сразу две записи (`A` и `AAAA`) для каждого домена. Устройства с IPv6 подключаются по чистому IPv6-каналу, а IPv4-клиенты работают стабильно через WAN или туннель.
* **Авто-апдейт через GitHub Actions:** Ежедневно в 03:00 парсит и объединяет списки, обновляя `lists/domains.txt` для Nginx и `mega_hosts_template.txt` для ваших роутеров. VPS и роутеры автоматически подтягивают обновления по cron.

## 🚀 Инструкция: Как развернуть на новом сервере (VPS)

### 1. Подготовка сервера
Зайдите на новый VPS-сервер по SSH:
```bash
ssh root@ВАШ_IP
```

### 2. Установка в одну команду на чистом сервере
Выполните одну строку в терминале чистого сервера (скрипт сам проверит и установит `git` и `curl`, склонирует репозиторий и настроит комплекс):
```bash
curl -sSL https://raw.githubusercontent.com/uraz0v/sni-proxy/main/install.sh | bash -s ваш-домен.com
```

*(Либо классическим способом: `git clone https://github.com/uraz0v/sni-proxy.git /opt/sni-proxy && cd /opt/sni-proxy && ./deploy.sh ваш-домен.com`)*

> **Что произойдет автоматически:**
> 1. **Проверка окружения (`install.sh`):** Проверяется и при необходимости устанавливается `git` и `curl`.
> 2. **Генерация параметров (`generate_env.sh`):** Создается файл `.env` со случайным криптостойким путем к веб-панели (`XUI_PATH`), секретным путем подписки (`SUB_PATH`), надежным логином и паролем администратора (`XUI_USER`, `XUI_PASSWORD`) и маскировкой (`REALITY_SNI=www.nvidia.com`).
> 3. **Установка системных пакетов и очистка:** Устанавливаются `openssl`, `socat`, `cron`, часовой пояс Екатеринбурга и Docker. На AlmaLinux/RHEL/CentOS автоматически отключается служба Cockpit (порт 9090) для освобождения памяти и закрытия портов.
> 4. **SSL-сертификат (`setup_ssl.sh`):** Автоматически устанавливается `acme.sh`, запускается Nginx для проверки домена и выпускается боевой сертификат Let's Encrypt.
> 5. **Запуск сервисов:** Разворачиваются контейнеры `sni_proxy` (порт 443 + сайт-маскировка) и `3x_ui` (портативная БД в `./db/`).
> 6. **Автонастройка 3X-UI (`init_xui.py`):** Панель изолируется на `127.0.0.1:53273`, сервис подписок изолируется на `127.0.0.1:2096`, генерируются ключи X25519, имя ноды и клиента автоматически задаются по 3-му уровню домена, создается инбаунд VLESS-Reality на порту 8443 с uTLS-отпечатком `firefox`, выпускается API-токен и настраивается `externalProxy` для порта 443.
> 7. **Выдача реквизитов:** В консоль и в файл `client_vless.txt` выводятся URL скрытой панели, логин, пароль, секрет панели (Secret), реквизиты подключения ноды к мастер-панели (External Node / API), **ссылка на подписку (Subscription URL)** и **прямая ссылка `vless://...` для клиента (uTLS Firefox)**.
> 8. **Регламентные задачи:** Настраивается автообновление списков в `cron` в 04:00.

### 4. Ручное управление параметрами (.env)
Вы можете сгенерировать или переконфигурировать файл `.env` вручную:
```bash
./generate_env.sh [ваш-домен.com]
```
Переменные файла `.env`:
* `SERVER_DOMAIN` — домен вашего VPS для Let's Encrypt и клиентов.
* `XUI_PATH` — секретный путь к панели (например, `/ovrIkhdXJlP0Y1iC/`).
* `SUB_PATH` — секретный путь подписки, защищенный от сканеров ТСПУ (например, `/s_BlqQuqm2c3QZ/`).
* `REALITY_SNI` — домен маскировки Reality (по умолчанию `www.nvidia.com`).
* `ACME_EMAIL` — email для уведомлений Let's Encrypt.
* `XUI_USER` и `XUI_PASSWORD` — логин и пароль администратора панели 3X-UI.
* `XUI_API_TOKEN` — API-токен для подключения ноды к мастер-панели (External Node).
*(Файл `.env` исключен из Git-репозитория и гарантирует сохранность ваших паролей).*

## 🌐 Инструкция: Как настроить роутер OpenWrt

Чтобы домашние устройства прозрачно использовали прокси для ИИ-сервисов, необходимо обновить файл `hosts` на роутере.

Скрипт автоматически скачивает сгенерированный шаблон, подставляет IPv4 и (опционально) IPv6 вашего VPS, делает резервную копию системного `hosts` и настраивает ежедневное обновление в `cron`:

1. Подключитесь к роутеру по SSH:
   ```bash
   ssh root@192.168.1.1
   ```
2. Скачайте и запустите скрипт (поддерживает как IPv4-only, так и Dual-Stack):
   ```bash
   curl -sL -o /etc/update_router_hosts.sh https://raw.githubusercontent.com/uraz0v/sni-proxy/main/update_router_hosts.sh && sh /etc/update_router_hosts.sh ВАШ_VPS_IPv4 [ВАШ_VPS_IPv6]
   ```
   *(Пример с Dual-Stack: `... && sh /etc/update_router_hosts.sh 1.2.3.4 2001:db8::1`)*  
   *(Пример только IPv4: `... && sh /etc/update_router_hosts.sh 1.2.3.4`)*

Скрипт проверит изменения, обновит `hosts`, перезапустит Dnsmasq и добавит задачу в cron на 05:00. Пользовательские записи (до маркера `# --- SNI PROXY AUTOGENERATED ---`) сохраняются нетронутыми!

## 📁 Структура проекта

* **`nginx.conf`** — конфигурация Nginx (L4 stream для SNI-маршрутизации и Reality + L7 HTTP для сайта-маскировки и реверс-прокси 3X-UI).
* **`docker-compose.yml`** — запуск контейнера Nginx в режиме сети `host` с пробросом портов 80 и 443, монтированием сертификатов и сайта-маскировки.
* **`entrypoint.sh`** — скрипт инициализации контейнера: автоматическое связывание SSL-сертификатов, генерация `whitelist_domains.conf` и подстановка `XUI_PATH`.
* **`camouflage/`** — адаптивный статический сайт-маскировка **ApexEdge** (HTML5/CSS, без внешних CDN, поддержка темной темы).
* **`install.sh`** — единый онлайн-установщик через curl (автоустановка git/curl, клонирование и запуск деплоя).
* **`deploy.sh`** — мастер первичной установки VPS «под ключ» в одну команду (генерация .env, Docker, acme.sh, SSL, запуск и cron).
* **`generate_env.sh`** — скрипт интерактивной генерации случайных параметров, путей, паролей и файла `.env`.
* **`setup_ssl.sh`** — скрипт автоматической установки `acme.sh` и выпуска боевого Let's Encrypt SSL-сертификата.
* **`init_xui.py`** — скрипт автоматической настройки 3X-UI с нуля (создание БД, привязка к `127.0.0.1:53273`, установка пароля админа, выпуск API-токена для подключения ноды, генерация ключей Reality X25519, отпечатка uTLS `firefox`, инбаунда 8443 и готовой клиентской ссылки `vless://`).
* **`update_lists.sh`** — скрипт ежедневного обновления на VPS (git pull и reload Nginx).
* **`update_router_hosts.sh`** — скрипт для маршрутизаторов OpenWrt с защитой от сбоев и поддержкой Dual-Stack.
* **`lists/custom_domains.txt`** — файл для добавления собственных доменов в прокси.
* **`lists/domains.txt`** — единый сгенерированный список доменов для фильтрации Nginx.
* **`mega_hosts_template.txt`** — сгенерированный шаблон hosts для роутеров OpenWrt.
* **`generate.sh`** — скрипт сборки и дедупликации списков доменов.
* **`.github/workflows/update.yml`** — GitHub Actions для ежедневного обновления списков по расписанию.
